# 本地浏览器工作台

工作台通过 MoonBit native 服务生成真实上下文。在浏览器中选择授权目录、切换全文/骨架/混合模式，查看代码对照、完整文档 token 数及预算，再下载 JSON。

## 启动

当前源码安装后运行：

```sh
moon-repomix ./project --webui
```

打开终端显示的 `http://127.0.0.1:8765`。更换端口：

```sh
moon-repomix ./project --webui --webui-port 8795
```

也可以直接从源码运行，在仓库根目录执行：

```sh
moon run src/cmd/moon-repomix --target native --release -- . --webui --tokenizer-path assets/tokenizer-o200k_base.tiktoken
```

词表旁须有 `webui/index.html`、`webui/app.css` 和 `webui/app.js`。源码已经提供 `assets/webui/`；安装和平台归档会将三个文件一起放进 `share/moon-repomix/webui/`。移动安装目录时保留 `bin/` 与 `share/` 的相对位置。服务运行不需要 Node.js；按 Ctrl+C 停止。

## 生成与对照

1. 选择仓库目录。目录浏览器只展示启动命令授权工作区中的子目录；也可直接使用工作区根。
2. 选择全文、骨架或混合模式。高级设置中的 include 与 keep-full 按所选目录解释；混合模式为命中的文件保留全文。
3. 点击“生成上下文”。界面显示本次真实 Native 结果；修改配置后需要重新生成，先前结果仍可查看。
4. 选择结果文件比较原文与输出，或查看完整 JSON。下载保留 Native 返回的完整字符串。

token 数针对最终渲染 JSON，包含目录、包装和元数据。预算超限会提示并保留完整结果。全文对照与骨架结果分别通过安全打包流程读取；生成时保持源码稳定，以便逐文件比较。

## 工作区与资源限制

服务只监听 `127.0.0.1`，授权范围由启动命令中的目录确定。浏览器中的路径不能越过该目录，也不能通过符号链接进入外部目录。仓库配置不会自动加载，扫描始终启用；界面按既有文件选择与扫描流程排除不适合分享的内容。扫描覆盖范围见 [安全说明](../SECURITY.md)。

| 项目 | 工作台上限 |
| --- | ---: |
| 单次普通候选文件 | 2,000 |
| 每次打包原始读取 | 16 MiB |
| 单文件 | 2 MiB |
| 含全文对照的 JSON 响应 | 16 MiB |
| 单次生成 | 60 秒 |

命令行指定更小的文件数、总读取或单文件限额时使用更小值。压缩生成包含全文对照和所选模式的两次打包；两次均独立接受输入限额和扫描。工作台一次只处理一个生成请求，忙时稍后重试。

这是可信本机用户的只读服务：不执行仓库命令、不向仓库写输出，下载由浏览器保存。HTTP Host、Origin 和自定义请求头检查限制跨站访问；该服务不是多用户托管接口，也不将并发敌对文件系统修改视为已经隔离。

## 常见问题

- **端口占用**：更换 `--webui-port`，在浏览器打开新地址。
- **启动后找不到页面资源**：确认使用完整安装目录，或在源码命令中传入 `assets/tokenizer-o200k_base.tiktoken`；静态文件与词表放在上述相对位置。
- **生成失败**：按页面提示缩小 include、选择更小子目录或减少文件；修正后重新生成。旧结果不代表失败请求已成功。
- **某个文件没有出现**：它可能被 ignore、文件类型或扫描排除。普通 CLI/SDK 的详细解释入口见 [入选原因](selection-explanation.md)。
